# Миграция на извлечение всех полей и сохранение в БД

## Что изменилось

### 1. Извлечение данных
- **Было:** Извлекалось 2 поля (Номер заявки, Итоговая стоимость)
- **Стало:** Извлекается 13 полей из БД схемы

### 2. Хранение данных
- **Было:** CSV файлы
- **Стало:** DuckDB database

### 3. Язык интерфейса
- **Было:** Английский
- **Стало:** Русский

## Новые модули

- `excel_agent/db_manager.py` - менеджер для работы с БД

## Изменения в конфигурации

Нужно создать БД перед первым запуском:

```bash
python3 -m db.create_base_table
```

## Обновленные файлы

1. `excel_agent/config.py` - новые целевые колонки
2. `excel_agent/db_manager.py` - работа с БД (новый)
3. `excel_agent/column_mapper.py` - поиск всех полей
4. `excel_agent/graph.py` - извлечение всех полей
5. `excel_agent/react_agent.py` - интеграция с БД, русский язык
6. `chat_app.py` - русский интерфейс

## Как это работает

### Входные данные
- Excel файлы в `data/`
- Код филиала (из UI)
- Наименование подрядчика (из UI)

### Процесс
1. Агент читает Excel файл
2. LLM ищет все 13 полей в колонках
3. Данные извлекаются
4. Сохраняются в DuckDB с метаданными

### Выходные данные
- Записи в таблице `processed_requests`
- Можно запрашивать через SQL

## Примеры запросов

```python
from excel_agent.db_manager import get_db_manager

db = get_db_manager()

# Статистика
stats = db.get_statistics()
print(f"Всего записей: {stats['total_records']}")

# Запрос заявок
df = db.query_requests(branch_code="BRN001", limit=50)
print(df.head())
```
