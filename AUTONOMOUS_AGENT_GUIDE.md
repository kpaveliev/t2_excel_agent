# 🤖 Autonomous Agent Guide

Руководство по использованию автономного агента с возможностью взаимодействия с человеком.

---

## 🎯 Концепция

**Один React Agent** который может:
- 🚀 **Автоматически обрабатывать** файлы через встроенный пайплайн
- 🤔 **Спрашивать человека** когда возникают сомнения
- 🔍 **Исследовать данные** используя набор инструментов
- 💬 **Общаться** на естественном языке

---

## 🛠️ Инструменты агента

### Новые инструменты для автономной работы:

#### 1. `run_pipeline` 
Запускает полный пайплайн обработки для **одного файла**:
- Читает Excel файл
- Находит нужные колонки с помощью LLM
- Извлекает данные
- Сохраняет результат

```python
run_pipeline(
    filename="report.xlsx",
    require_high_confidence=False  # True = предупреждает о низкой уверенности
)
```

#### 2. `run_batch_pipeline`
Запускает пайплайн для **всех файлов** в папке data/:

```python
run_batch_pipeline(
    auto_mode=True,              # True = обрабатывает всё автоматически
    require_high_confidence=False # True = помечает файлы для проверки
)
```

#### 3. `ask_human`
Задает вопрос человеку и ждет ответа:

```python
ask_human(
    question="Какую колонку использовать для номера заявки?",
    options=["Номер заявки", "№ заявки", "Order Number"],
    context="Файл: report.xlsx, Лист: Основной"
)
```

## 🎛️ Режимы работы

### Режим 1: 🚀 Fully Automatic (Полностью автоматический)

**Что делает:**
- Обрабатывает ВСЕ файлы без остановок
- Принимает любую уверенность (high, medium, low)
- Не спрашивает подтверждений

**Когда использовать:**
- Файлы имеют стандартную структуру
- Доверяете AI полностью
- Нужна максимальная скорость

**Пример:**
```
Пользователь: Обработай все файлы автоматически

Агент: Запускаю обработку в автоматическом режиме...
       [использует run_batch_pipeline(auto_mode=True)]
       
       ✅ Обработано: 3 файла
       📊 Всего строк: 245
```

---

### Режим 2: 🤔 Ask When Unsure (Спрашивать при сомнениях)

**Что делает:**
- Обрабатывает файлы с высокой уверенностью автоматически
- Останавливается когда confidence != "high"
- Использует `ask_human` для подтверждения

**Когда использовать:**
- Файлы могут иметь разную структуру
- Хотите контролировать качество
- Готовы потратить время на проверку

**Пример:**
```
Пользователь: *нажимает "Start Processing" в режиме "Ask When Unsure"*

Агент: Начинаю обработку файлов...
       
       ✅ file1.xlsx - обработан (confidence: high)
       ✅ file2.xlsx - обработан (confidence: high)
       ⚠️  file3.xlsx - нужна проверка (confidence: medium)
       
       🤔 [WAITING FOR HUMAN RESPONSE]
       
       Context: file3.xlsx, Sheet: Отчет
       
       Question: Я нашел две возможные колонки для номера заявки.
                 Какую использовать?
       
       Options:
       1. Номер заявки
       2. № заявки
       
       Please provide your answer below...

Пользователь: Первую

Агент: Спасибо! Использую "Номер заявки"
       ✅ file3.xlsx - обработан успешно
       
       📊 Все файлы обработаны!
```

---

### Режим 3: 👁️ Manual Review (Ручная проверка)

**Что делает:**
- Показывает каждый файл перед обработкой
- Спрашивает подтверждение на каждый шаг
- Максимальный контроль

**Когда использовать:**
- Критически важные данные
- Первая обработка новых файлов
- Обучение/проверка работы агента

**Пример:**
```
Пользователь: Обработай файлы с ручной проверкой

Агент: Найдено 3 файла. Начинаю проверку...
       
       📄 Файл 1/3: report1.xlsx
       [использует get_excel_sheets, preview_sheet_data]
       
       Листы: Основной, Детализация
       Превью: [показывает данные]
       
       [использует ask_human]
       Обработать этот файл? (Yes/No)

Пользователь: Yes

Агент: [использует run_pipeline("report1.xlsx")]
       ✅ Обработан
       
       Переходим к следующему файлу...
```

## 🔧 Техническая архитектура

```
┌─────────────────────────────────────────┐
│      React Agent (Orchestrator)         │
│                                         │
│  - Получает запрос от пользователя      │
│  - Рассуждает (Reasoning)               │
│  - Выбирает инструмент (Action)         │
│  - Наблюдает результат (Observation)    │
│  - Повторяет пока задача не выполнена   │
└─────────────────────────────────────────┘
              ↓ использует
┌─────────────────────────────────────────┐
│              Tools                      │
│                                         │
│  Exploration:                           │
│  - list_excel_files                     │
│  - get_excel_sheets                     │
│  - preview_sheet_data                   │
│                                         │
│  Processing:                            │
│  - run_pipeline ──→ StateGraph          │
│  - run_batch_pipeline ──→ StateGraph    │
│  - extract_data                         │
│                                         │
│  Interaction:                           │
│  - ask_human ──→ Chat Interface         │
└─────────────────────────────────────────┘
              ↓
┌─────────────────────────────────────────┐
│        StateGraph Workflow              │
│  (Существующий пайплайн)                │
│                                         │
│  read_file → find_columns → extract     │
└─────────────────────────────────────────┘
```

## 💡 Советы и лучшие практики

### Для пользователя:

1. **Начните с "Ask When Unsure"** - золотая середина между скоростью и контролем

2. **Используйте natural language** - агент понимает:
   - "Обработай всё автоматически"
   - "Process files but ask me if you're not sure"
   - "Покажи мне что в первом файле перед обработкой"

3. **Агент помнит контекст** - можно ссылаться на предыдущие сообщения:
   ```
   User: Покажи файлы
   Agent: [показывает 3 файла]
   
   User: Обработай второй
   Agent: [обрабатывает второй файл из списка]
   ```

4. **Используйте кнопки** - быстрый способ запуска без typing

### Для агента (система):

Агент следует этим правилам:
- ✅ **Проактивность**: предлагает использовать run_pipeline когда пользователь хочет обработать файлы
- ✅ **Прозрачность**: объясняет что делает и почему
- ✅ **ask_human > guessing**: спрашивает вместо угадывания когда не уверен
- ✅ **Краткость**: даёт чёткие резюме результатов

## 🐛 Troubleshooting

### Агент не спрашивает в режиме "Ask When Unsure"

**Причина**: Все файлы имеют high confidence  
**Решение**: Это нормально! Агент спрашивает только когда действительно не уверен

### Агент спрашивает слишком часто

**Причина**: Режим "Manual Review" или сложная структура файлов  
**Решение**: Переключитесь на "Fully Automatic" если доверяете результатам

### ask_human не работает (агент не ждет ответа)

**Причина**: Это известное ограничение - нужна доработка  
**Решение**: Пока что агент возвращает маркер, вы отвечаете в следующем сообщении
